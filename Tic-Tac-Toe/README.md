# 🎮 Tic Tac Toe

A simple Tic Tac Toe game built using React and Tailwind CSS.

## ✨ Features

- ✅ Player turn switching
- ✅ Winner detection
- ✅ Draw detection
- ✅ Reset game button
- ✅ Responsive UI

## 🛠️ Tech Stack

- React
- JavaScript
- Tailwind CSS

## 🚀 Run Locally

```bash
npm install
npm run dev
```
